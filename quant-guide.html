Part 1: Beta questions

Think of Beta as the volume knob connecting your investment to the broad market.

BETA 01

What formula defines Beta in a one-factor OLS regression?

Correct answer: Asset–benchmark covariance ÷ benchmark-return variance.
The simple idea

Draw benchmark returns left-to-right and asset returns bottom-to-top. OLS draws the best straight line through those dots. Beta is the line’s slope: how much the fitted asset return changes when the benchmark changes by one unit.

Covariance measures whether the asset and benchmark move together. But covariance grows when the benchmark itself is more jumpy, so we divide by the benchmark’s own variance to put the movement on the correct scale.

β = Cov(Rasset, Rbenchmark) / Var(Rbenchmark)
Worked example. Covariance = 0.018 and benchmark variance = 0.015.
β = 0.018 ÷ 0.015 = 1.2.
The fitted relationship says a 1% benchmark move corresponds to roughly a 1.2% asset move.
Why the traps are wrong: Dividing by asset variance reverses the regression’s scaling. Correlation is only standardized co-movement; it has no return scale, so correlation ÷ variance is not the slope.

Remember: in “asset return ON benchmark return,” divide by the variance of the benchmark.

BETA 02

What does an asset Beta of 1.2 actually mean?

Correct answer: A 1% benchmark move corresponds to a 1.2% change in the asset’s fitted return, keeping the intercept fixed.

Beta is an estimated average relationship, not a promise. The complete fitted line also has an intercept, usually called Alpha, plus a residual—the part the line fails to predict.

Fitted asset return = Alpha + 1.2 × benchmark return
Example. If Alpha is 0.1% per month:
Benchmark +1% → fitted asset = 0.1% + 1.2×1% = +1.3%.
Benchmark −2% → fitted asset = 0.1% + 1.2×(−2%) = −2.3%.
The real result can be different because of the residual.
Two common mistakes: It does not mean the asset earns exactly 1.2% whenever the market rises. It also does not guarantee the asset is 20% more volatile; asset-specific noise affects total volatility.

Beta = modeled market sensitivity, not certainty and not total risk.

BETA 03

How do you calculate a portfolio’s Beta?

Correct answer: Add each holding’s Beta multiplied by its portfolio weight.
βportfolio = w₁β₁ + w₂β₂ + … + wₙβₙ

A large holding should affect the portfolio more than a tiny holding. That is why weights matter.

Example. 60% of the money is in Fund A with Beta 1.1; 40% is in Fund B with Beta 0.5.
Portfolio Beta = 0.60×1.1 + 0.40×0.5
= 0.66 + 0.20 = 0.86.
A 1% benchmark move therefore corresponds to about a 0.86% fitted portfolio move.
Why not a simple average? (1.1+0.5)/2 = 0.8 assumes equal 50/50 positions, which you do not have. Multiplying Betas together has no useful portfolio meaning here.

Weight, multiply, add.

BETA 04

How large must a benchmark hedge be to make first-order Beta zero?

Correct answer: Hedge notional = −bV.

A position worth V with Beta b contains approximately b×V Beta-dollars. A benchmark position with Beta 1 contributes one Beta-dollar per dollar. Use the same exposure in the opposite direction.

Asset exposure = bV   →   Hedge = −bV
Example. Portfolio value V = $100,000 and Beta b = 1.3.
Exposure = 1.3×$100,000 = $130,000.
Short $130,000 of the Beta-1 benchmark.
Net exposure = +$130,000 − $130,000 = $0.
Important limitation: This is “first-order” neutral, meaning neutral for a small market move under today’s estimated Beta. Betas change, tracking is imperfect, and the portfolio still has asset-specific risk. −V/b would under-hedge; −b²V would over-hedge.

Beta-dollars = Beta × dollars. Cancel them with the negative amount.

BETA 05

What if benchmark variance is zero?

Correct answer: Beta is undefined because the formula divides by zero.

OLS can estimate sensitivity only if the input changes. If every benchmark return is identical, there is no “when the market changes” information in the sample.

β = Cov(asset, benchmark) / 0   →   undefined
Visual example. Imagine benchmark returns for five periods are 0%, 0%, 0%, 0%, 0%. Every x-coordinate on the chart is the same. You cannot identify the tilt of a line from a vertical stack of points.
Undefined is not zero. Zero Beta means the estimated slope exists and equals zero. Here no unique slope can be estimated. The asset’s volatility is a different number and cannot replace the missing denominator.

No benchmark movement means no information about benchmark sensitivity.

Part 2: Alpha questions

These questions test whether an apparent edge is measured fairly and sized sensibly.

ALPHA 01

What is the Information Ratio?

Correct answer: Expected active return ÷ tracking error.

Active return is portfolio return minus benchmark return. Tracking error is the volatility of that difference. So the Information Ratio asks how much benchmark-beating return you earn for each unit of inconsistency in that benchmark-beating return.

IR = E(Rportfolio − Rbenchmark) / Vol(Rportfolio − Rbenchmark)
Example. Fund return = 10% yearly; benchmark = 8%. Active return = 2%. Tracking error = 4%.
IR = 2% ÷ 4% = 0.50.
A higher positive IR means more active return relative to active wobble, but it does not guarantee future skill.
Do not confuse it with Sharpe: expected return above cash divided by total portfolio volatility is the Sharpe Ratio. Benchmark volatility alone ignores how the portfolio and benchmark move relative to each other.

Information Ratio = active reward / active risk. Sharpe = excess reward / total risk.

ALPHA 02

How does purging remove overlapping-label leakage?

Correct answer: Remove every training observation whose label interval overlaps a test label interval.

A row’s label may use future prices. For example, the label on January 8 could be the return from January 8 through January 13. If the test period begins January 10, that training label contains prices from the test period. The model has indirectly seen its exam answers.

Timeline example.
Training label: Jan 8 ───────── Jan 13
Test label:        Jan 10 ───────── Jan 15
The shared Jan 10–13 information leaks. Purge the Jan 8 training row.

Embargo is a separate safety buffer placed near the test block to reduce nearby dependence. It can help, but it does not replace removing observations that definitely overlap.

Why shuffling fails: moving leaked rows around does not unsee the future. The information remains inside training.

Known overlap: purge it. Possible nearby dependence: add an embargo.

ALPHA 03

Why is the derivative of portfolio variance 2(Σw)ᵢ?

Correct answer: Twice the i-th element of Σw.

w is the vector of portfolio weights. Σ is the covariance matrix: diagonal entries are individual variances and off-diagonal entries describe co-movement. The derivative asks: “If I increase weight i by a tiny amount, how quickly does total variance change right here?”

V(w)=wᵀΣw   and, when Σ is symmetric,   ∂V/∂wᵢ=2(Σw)ᵢ
Two-asset example.
Σ = [[0.04, 0.01], [0.01, 0.09]], w = [0.5, 0.5].
Σw = [0.04×0.5+0.01×0.5, 0.01×0.5+0.09×0.5]
= [0.025, 0.050]. Multiply by 2 → gradient = [0.050, 0.100].
Locally, increasing asset 2’s weight increases variance about twice as fast.
Why the other answers fail: Σᵢᵢ is only the asset’s own variance; it ignores current weights and correlations. Squaring (Σw)ᵢ is not the derivative. The 2 appears because the symmetric quadratic contains matching cross-terms.

Multiply Σ by w, select component i, multiply by 2.

ALPHA 04

What is regression Alpha?

Correct answer: The intercept—expected return not explained by the included factor exposures.
Return = Alpha + β₁Factor₁ + β₂Factor₂ + … + residual

The slopes (Betas) say how exposed the strategy is to known factors. The intercept is the average fitted return left over when those factor returns are zero. That intercept is regression Alpha.

Example. A strategy earns an average 1.0% per month. Its market exposure explains 0.7%; other included factors explain another 0.2%. Roughly 0.1% remains as fitted monthly Alpha.
Important warnings: Alpha depends on which factors you include. Add a missing factor and “Alpha” may disappear. Residual volatility is the random spread around the line, not the intercept. Trading costs can also erase gross Alpha.

Slope = exposure. Intercept = Alpha. Residual = unexplained period-by-period noise.

ALPHA 05

What does classical Kelly betting maximize?

Correct answer: Expected logarithmic wealth growth.

Kelly chooses the fraction of wealth that maximizes long-run compound growth across repeated independent bets with known probabilities. Log wealth punishes near-ruin because percentage losses and gains are asymmetric: lose 50%, and you need +100% just to recover.

Choose f to maximize E[log(next wealth)]
Even-money bet: f* = p − q = 2p − 1
Example. Win probability p = 60%; loss probability q = 40%; win/loss payoff is 1:1.
Full Kelly fraction = 0.60 − 0.40 = 20%.
With $10,000, full Kelly bets $2,000. Many practitioners use half-Kelly ($1,000) because the estimated 60% probability may be wrong.
Kelly is not “safe.” It can still create painful drawdowns. Maximizing raw expected terminal wealth can recommend reckless sizing; minimizing variance for a target return is mean-variance optimization, a different goal. Kelly’s clean answer also assumes probabilities are known and opportunities are independent—strong assumptions in markets.

Kelly maximizes long-run log growth, not comfort, certainty, or raw average dollars.
